# 三个一人创业原型

需要 Node.js 22 或以上，无需安装依赖。在本目录运行，默认读取各项目自带的虚构示例。命令末尾可加自定义 UTF-8 JSON 文件路径。结果输出到标准输出，可用重定向保存。

| 原型 | 命令 | 输入与输出 |
| --- | --- | --- |
| 电商退款对账 | `node refund-reconciliation/index.mjs` | 输入订单、退款、结算三组记录，金额用整数分。按订单号合计，输出预期到账与实际到账的差额线索和数组内从 1 开始的行号。 |
| AI 客服回归体检 | `node ai-support-regression/index.mjs` | 输入每个租户的历史案例、新旧回答、必含和禁用短语。输出用例状态和出现回归的租户。 |
| 工业视觉误检复盘 | `node vision-error-review/index.mjs` | 输入已标注和已推理的二分类记录。按产线、班次等分组，输出漏检和误报样本及对应比率。分母为零时返回 null。 |

退款对账适用于按订单号结算且预期金额等于订单金额减退款的账单。平台费用、补贴或汇率需在接入真实账单时建模。客服体检用短语规则验证已生成的回答。工业视觉复盘使用已有标签和预测，图片字段用于定位样本。实际输入结构见各目录的 sample.json。

## 浏览器工作台

运行 `node server.mjs`，在浏览器打开 http://127.0.0.1:4173。选择一个原型，点击「运行分析」即可试用样例，也可以上传自己的 JSON 并下载结果。GitHub 仓库页面展示源码，工作台由本地 Node.js 服务运行。
